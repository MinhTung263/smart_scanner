# Smart Scanner

A powerful, high-performance smart barcode and QR code scanner built with Flutter and Google ML Kit.

## Features

- **Blazing Fast Scanning**: Powered by Google ML Kit for on-device, real-time barcode and QR code recognition.
- **Multiple Formats**: Supports a wide range of barcode formats (QR, EAN-13, UPC-A, Code 128, etc.).
- **Modern UI**: Clean, glassmorphic design that feels premium and intuitive.
- **Cross-Platform**: Built with Flutter to run seamlessly on iOS and Android.

## Getting Started

1. Clone the repository.
2. Ensure you have the latest version of Flutter installed.
3. Run `flutter pub get` to install dependencies.
4. Run the app using `flutter run` on your connected physical device (scanning requires a real camera).

## Requirements

- **iOS**: iOS 12.0 or higher.
- **Android**: Minimum SDK version 21 (Android 5.0).
